# مسبحة الأذكار 📿

مسبحة إلكترونية عربية تعمل كتطبيق ويب تقدّمي (PWA): تُثبَّت على الجوال، وتعمل بدون إنترنت، وتحفظ عدّاداتك على جهازك.
مبنية بـ Vite و JavaScript عادي، بدون أي framework وبدون backend.

## المزايا

- **عدّاد دائري**: اضغط على الدائرة للعدّ، أو زر **المسافة** على الكمبيوتر (و`Ctrl+Z` للتراجع).
- **اهتزاز** خفيف مع كل تسبيحة واهتزاز مميّز عند إكمال العدد (يمكن إيقافهما من الإعدادات).
- **تراجع، تصفير، تعديل العدد، الانتقال للذكر التالي**.
- **الأقسام**: أذكار مطلقة، الصباح والمساء، بعد الصلاة، النوم والاستيقاظ، استغفار، الرزق والدَّين، أدعية جامعة، و**أذكاري** (أذكار تضيفها بنفسك بنص وعدد).
- **وقت كل ذكر** مكتوب بخط رفيع فوقه (بعد الصلاة، في أي وقت، حين تأوي إلى فراشك...).
- **زر «الفضل والحديث» بجانب كل ذكر** يفتح صفحته الخاصة: الفضل مختصرًا، **نص الحديث كاملًا** من مصدره، الراوي، التخريج (المصدر والرقم)، الدرجة ومن حكم بها، وحكم الترمذي من كتابه إن وُجد.
- **أسباب الرزق من القرآن والسنة**: صفحة تُفتح من قسم «الرزق والدَّين».
- **مجموع يومي** يتصفّر تلقائيًا كل يوم، مع مجموع آخر ٧ أيام والمجموع الكلّي في الإعدادات.
- **وضع فاتح وداكن وتلقائي** (يتبع إعداد الجهاز).
- **يعمل بدون إنترنت** والخطوط مضمّنة في التطبيق.

## التشغيل محليًا

يحتاج [Node.js](https://nodejs.org) الإصدار 20 أو أحدث.

```bash
npm install        # تثبيت الحزم
npm run dev        # خادم التطوير على http://localhost:5173
npm run build      # بناء نسخة الإنتاج في مجلد dist
npm run preview    # معاينة نسخة الإنتاج (هنا يعمل الـ Service Worker)
```

> ملاحظة: خاصية العمل بدون إنترنت وزر التثبيت يعملان في نسخة الإنتاج (`build` ثم `preview`) أو بعد النشر، وليس في `npm run dev`.

لتجربته على جوالك في نفس الشبكة: `npm run preview -- --host` ثم افتح العنوان الظاهر. (التثبيت الكامل يتطلب HTTPS، لذا الأفضل التجربة بعد النشر.)

## بنية المشروع

```
├── index.html               الصفحة الرئيسية والنوافذ المنبثقة
├── vite.config.js           إعداد Vite و vite-plugin-pwa (الـ manifest والـ Service Worker)
├── pwa-assets.config.js     إعداد توليد الأيقونات
├── public/                  الأيقونات (logo.svg هو المصدر)
└── src/
    ├── data/adhkar.json     ← كل البيانات: الأقسام، الأذكار، أسباب الرزق
    ├── main.js              منطق الواجهة
    ├── store.js             الحفظ في localStorage والمجموع اليومي
    ├── icons.js             أيقونات SVG
    └── style.css            التصميم والوضع الفاتح/الداكن
```

## تعديل الأذكار

كل البيانات في `src/data/adhkar.json` منفصلة عن الكود. لإضافة ذكر أضف عنصرًا إلى مصفوفة `adhkar`:

```json
{
  "id": "meaningful-unique-id",
  "when": "في أي وقت",
  "category": "mutlaq",
  "text": "نص الذكر",
  "count": 33,
  "countFromHadith": false,
  "virtue": "الفضل مختصرًا بالمعنى",
  "narrator": "اسم الراوي",
  "hadith": "نص الحديث كاملًا من المصدر",
  "classification": "رواه مسلم",
  "grade": "صحيح",
  "sources": [{ "book": "صحيح مسلم", "number": "1234", "grade": "صحيح" }],
  "verified": true
}
```

- `category` واحد من: `mutlaq`، `sabah`، `salah`، `nawm`، `istighfar`، `rizq`، `jami`.
- `sources` قائمة المصادر، ولكل مصدر `grader` (من حكم بالدرجة) و`tirmidhiSays` (حكم الترمذي) اختياريًّا.
- `id` يجب أن يكون فريدًا ولا يُغيَّر لاحقًا، لأن العدّادات المحفوظة مربوطة به.
- `countFromHadith`: ‏`true` إذا ورد العدد نصًّا في الحديث، و`false` إذا كان العدد اقتراحًا للتنظيم فقط.

### كيف تم التحقق من الأحاديث

طُوبق كل حديث آليًّا مع نصوص الكتب الستة في قاعدة [hadith-api](https://github.com/fawazahmed0/hadith-api) المفتوحة:

- وُجد الحديث بالرقم المذكور، واحتوى على العبارة المتوقعة.
- لفظ الذكر المعروض موجود حرفيًّا في نص الحديث، إلا في القرآن وفيما يُفهم من الحديث ولا يُنقل بلفظه، مثل «يسبّح مئة تسبيحة».
- نص الحديث المعروض منقول من المصدر كما هو.
- الدرجة: أحاديث الصحيحين صحيحة، ولغيرهما حكم الألباني. **استُبعد كل حديث ضعيف أو موضوع.**
- ترقيم صحيح مسلم بحسب محمد فؤاد عبد الباقي.

استثناء واحد: حديث «آية الكرسي دبر كل صلاة» (السنن الكبرى للنسائي) غير موجود في القاعدة، وهو معلَّم في التطبيق بأنه لم يُطابَق آليًّا.

في صفحة كل حديث رابط للبحث عنه في [الدرر السنية](https://dorar.net) لمن أراد المراجعة.

لتغيير الأيقونة: عدّل `public/logo.svg` ثم شغّل `npm run icons`.

## النشر

### Vercel (المستخدم حاليًا)

المشروع مربوط بمستودع GitHub، وVercel يتعرّف على Vite تلقائيًا:

- **Framework Preset:** ‏`Vite`
- **Build Command:** ‏`npm run build`
- **Output Directory:** ‏`dist`

كل `git push` إلى الفرع `main` ينشر نسخة جديدة تلقائيًا، وتصل للمستخدمين عبر الـ Service Worker عند فتح التطبيق.

### Cloudflare Pages

1. ارفع المشروع إلى مستودع على GitHub أو GitLab.
2. من لوحة Cloudflare: **Workers & Pages ← Create ← Pages ← Connect to Git** واختر المستودع.
3. الإعدادات:
   - **Framework preset:** ‏`Vite` (أو None)
   - **Build command:** ‏`npm run build`
   - **Build output directory:** ‏`dist`
4. اضغط **Save and Deploy**. ستحصل على رابط مثل `https://misbaha.pages.dev`.

أو مباشرة من الطرفية بدون Git:

```bash
npm run build
npx wrangler pages deploy dist --project-name misbaha
```

### Netlify

المشروع يحتوي ملف `netlify.toml` جاهزًا، فلا تحتاج لإدخال الإعدادات يدويًا.

1. ارفع المشروع إلى GitHub.
2. من Netlify: **Add new site ← Import an existing project** واختر المستودع، ثم **Deploy**.

أو بالسحب والإفلات: شغّل `npm run build` ثم اسحب مجلد `dist` إلى [app.netlify.com/drop](https://app.netlify.com/drop).

أو من الطرفية:

```bash
npm run build
npx netlify-cli deploy --prod --dir dist
```

## التثبيت على الجوال

- **أندرويد (Chrome):** افتح الموقع ← القائمة ⋮ ← **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
- **آيفون (Safari):** افتح الموقع ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

> ملاحظة: الاهتزاز غير مدعوم في Safari على آيفون، ويعمل على أندرويد.

## الخصوصية

لا يوجد خادم ولا تتبّع. كل البيانات (العدّادات، أذكارك، الإعدادات) محفوظة في `localStorage` على جهازك فقط، وتُحذف إذا مسحت بيانات المتصفح للموقع.
